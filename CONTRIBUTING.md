# Contribuindo com o Araru

Obrigado pelo interesse em contribuir.

1. Leia [docs/README.md](docs/README.md), [invariantes](docs/llm/constraints.md) e [protocolo de mudança](docs/llm/change-protocol.md).
2. Abra uma discussão/issue para mudanças arquiteturais ou de contrato.
3. Faça alterações pequenas e preserve dados, IDs, migrations e Range.
4. Adicione testes proporcionais e atualize a documentação.
5. Execute `npm run lint`, `npm test`, `npm run build` e `npm run docs:check`; use E2E para readers, PWA, proxy ou Docker.

Não inclua conteúdo protegido, credenciais, banco, livros ou caches no commit. Decisões significativas exigem ADR. A licença do projeto ainda está pendente; contribuições externas devem aguardar sua definição formal quando isso for juridicamente necessário.
